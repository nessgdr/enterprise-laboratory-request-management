# Screenshot Guide

Before publishing screenshots to GitHub, remove or obscure confidential information, tenant identifiers, personal email addresses, record GUIDs, and credentials.

Recommended screenshots:

1. Model-driven app — Laboratory Request form
2. Six-stage Business Process Flow
3. Active Laboratory Requests view
4. Dataverse schema/tables
5. Consolidated Power Automate approval flow
6. SPFx Laboratory Operations Dashboard
7. Power BI report/dashboard when finalized

Use descriptive filenames such as:
- `model-driven-request-form.png`
- `business-process-flow.png`
- `active-requests-view.png`
- `power-automate-approval-flow.png`
- `spfx-dashboard.png`
