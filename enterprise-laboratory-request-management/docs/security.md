# Security Design

The solution follows role-specific access rather than providing all users the same permissions.

## Personas
- Requester
- Manager
- Laboratory Supervisor
- Technician
- Administrator

## Design considerations
- Dataverse security roles
- Business units and owner/access teams where appropriate
- Record ownership
- Field-level security for sensitive information where required
- Confidentiality classification
- SharePoint permission management
- Least-privilege access
- Controlled service/connection ownership for automation
