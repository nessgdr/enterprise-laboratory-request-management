# Deployment & ALM

The solution should be packaged using Power Platform solutions and promoted through controlled environments.

## Deployment checklist
- Validate solution dependencies.
- Use connection references rather than personal hard-coded connections.
- Configure environment-specific values appropriately.
- Validate Dataverse security roles and teams.
- Share the model-driven application with intended roles.
- Validate flow ownership and service connections.
- Validate SharePoint site/library permissions.
- Validate Power BI workspace/report permissions.
- Run functional and user-acceptance testing before production release.
